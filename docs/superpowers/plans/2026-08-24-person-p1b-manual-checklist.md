# 人物 tab 浏览器手动验收清单（P1b）

前置：`make dev-restart` 后打开 http://localhost:8080 → 切「人物」tab。

1. 名册显示 owner「我」卡片（「我」徽标）
2. ＋ 新建：建「测试人物」→ 出现在名册；空名提交被拦；「收起」再开不残留旧输入
3. 点开「我」详情：分组属性区（Basic 等组名）+ 底部「＋ 加属性」「＋ 加关系」
4. 加属性 occupation=工程师 → 行内出现（人工 · 100% · 直述徽标）
5. 再加 occupation=教师 → 值变为教师；点 ⟲ 看「工程师 → 教师」历史（人工·修改）
6. 属性行 ✎ 改值 → 新值 + 历史留痕；🗑 删除 → 2 步确认 → 消失
7. 加关系：朋友 → 测试人物（下拉选）→ 关系区出现「朋友 → 测试人物」
8. 删关系 → 2 步确认 → 消失
9. 「从历史抽取画像」→ 摘要条（N 段录音统计）；如有 pending → 队列卡出现
10. 队列条目：冲突条目显示「现值 X → 建议改为 Y」；✓确认 → 名册角标数变化；✕放弃 → 条目消失
11. 「最近互动」🎤 点击 → 跳时间线并展开对应 session
12. 切换人物 A→B：A 的历史抽屉/加属性草稿不残留（B 的详情干净）
13. 归档测试人物 → 2 步确认 → 从名册消失

发现问题 → 反馈给 controller。

## P2b 大事记验收（2026-08-25 追加）

14. 详情「大事记」区：手动加「旅行·去云南旅游一周」（选日期）→ 按年分组出现（人工徽标）
15. 加低置信事件路径：从历史抽取画像 → 队列出现「大事记」条目（类型：标题 + 日期 + 置信度）→ 确认 → 详情事件转正
16. 事件删除 → 2 步确认 → 消失；名册 pending 角标联动
17. 切换人物再切回：加事件草稿不残留（对称清理）
18. 同行人物：加事件选 related → 详情行显示「与 X 同行/同场」

## P3b 状态&健康验收（2026-08-26 追加）

19. 详情「状态&健康」：切「体重」录入 3 笔不同日期 → 折线出现（端点值直标；hover 显示日期+值）
20. 切「情绪」录入/抽取 → 时间线列表（值+日期+来源徽标）
21. 「记一笔」空值被拦；日期默认今天；删除测点 2 步确认（删后折线/列表即时更新）
22. 「健康周期（敏感）」默认折叠 → 展开见免责文案 + 周期列表；收起再展开数据刷新、草稿不残留
23. 加周期（用药·降压药 anchor+period）→ 下次预测日期显示（估算提示脚注在场）
24. 队列出现「指标」「周期」条目（含值/日期）→ 确认流转
25. 切换人物再切回：指标表单/周期表单草稿不残留；健康区回到折叠态

## P4 生活轨迹验收（2026-08-26 追加）

26. 详情「生活轨迹」：手动加「通勤·地铁·40分钟」→ 列表出现（人工徽标 + meta 行）
27. 加 3 条不同日期活动 → 按时间升序排列；删除 2 步确认
28. 队列出现「活动」条目 → 确认流转；名册角标联动
29. 切换人物再切回：活动表单草稿不残留

## P5 跟进项验收（2026-08-26 追加）

30. 新建人物填空 display_name 提交 → 报错显示后端原文「display_name 不能为空」（非通用「请求失败」）
31. 新建人物表单声纹是下拉（含说话人名）；选已绑定声纹提交 → 409 显示「已绑定人物「XX」」
32. 「从历史抽取画像」点击后 spinner + 提示文案；完成后统计条出现
33. 归档测试人物 → 详情不可进、名册消失；DB 里其六平面行全 dismissed
34. 录音处理中 LLM 抖动（模拟）→ session 不再 failed，trace 记「画像抽取失败（非致命）」
